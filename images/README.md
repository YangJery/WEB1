# 사진 폴더

동작 사진을 이 폴더에 넣고 `js/data.js` 에서 파일 이름으로 연결합니다.

## 파일 이름 규칙

동작의 `id` 와 순번을 붙여 지으면 나중에 찾기 쉽습니다.

```
hundred-1.jpg      헌드레드 첫 번째 사진
hundred-2.jpg      헌드레드 두 번째 사진
roll-up-1.jpg      롤 업 첫 번째 사진
```

## 사진 크기

가로 1200px 안팎, 파일 하나당 300KB 이하를 권합니다.
휴대폰으로 찍은 원본은 보통 3~5MB라 그대로 올리면 사이트가 느려집니다.
저장할 때 크기를 줄이거나 화질을 조금 낮춰서 올리세요.

가로세로 4:3 비율로 맞추면 목록 화면의 카드가 가장 깔끔하게 나옵니다.

## 저작권

직접 찍은 사진이나 사용 허락을 받은 사진만 올리세요.
