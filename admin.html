시작하기

글을 올리려면 GitHub 토큰이 한 번 필요합니다. 토큰은 이 브라우저에만 저장되고 다른 곳으로 전송되지 않습니다.

토큰 만드는 방법
  1. GitHub → 오른쪽 위 프로필 → Settings
  2. 맨 아래 Developer settings
  3. Personal access tokens → Fine-grained tokens → Generate new token
  4. Repository access 에서 Only select repositories → WEB1 선택
  5. Permissions → Repository permissions → Contents 를 Read and write 로
  6. Expiration(기한)은 90일 정도로 두면 됩니다. 만료되면 새로 발급받아 다시 넣으세요.
  7. 생성 후 나오는 github_pat_... 문자열을 아래에 붙여넣습니다.
