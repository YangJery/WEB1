시작하기

글을 올리려면 GitHub 토큰이 한 번 필요합니다. 토큰은 이 브라우저에만 저장되고 다른 곳으로 전송되지 않습니다.

토큰 만드는 방법 (처음이거나 기한이 지났을 때)

아래 주소를 누르면 만드는 화면이 바로 열립니다. 메뉴에서 찾지 않아도 됩니다.

github.com/settings/personal-access-tokens/new

  1. Token name — 아무 이름이나. 예: pilates-admin
  2. Expiration — 90일 정도로 둡니다.
  3. Repository access → Only select repositories → WEB1 선택
  4. Permissions → Repositories 옆 + 버튼 → Contents 검색 → Read and write 로 지정
    Metadata 가 Read-only 로 같이 붙습니다. 필수 항목이니 그대로 두세요.
  5. 초록색 Generate token 누르기
  6. 나오는 github_pat_... 문자열을 복사해 아래에 붙여넣습니다.
    그 화면을 벗어나면 다시 볼 수 없습니다. 잃어버리면 같은 방법으로 새로 만들면 됩니다.

토큰은 비밀번호와 같습니다. 화면을 남에게 보여주거나 저장소 안의 파일에 적지 마세요.
